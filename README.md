# Guniapa

**Local skills. Trusted help. More opportunity.**

Guniapa is a planned service marketplace connecting customers with skilled women service providers for home, care, education, wellness, and workplace services.

## Vision

Make trusted local services easier to discover and help skilled women access more work opportunities.

## Planned Technology

- Backend: Python and Django REST Framework
- Frontend: React and TypeScript
- Database: PostgreSQL
- Future infrastructure: Docker, Redis, background jobs, and cloud hosting

## Project Status

Currently in development.
